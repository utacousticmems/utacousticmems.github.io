# Conferences and travel

Photos in this folder appear in the **Conferences and travel** album on the [Gallery page](https://utacousticmems.github.io/gallery/).

Each conference has its own folder here, named date first (for example `2026-05-asa-philadelphia`), and shows as its own group with a heading.

- **New conference:** **Add file → Upload files**, drag in a folder of photos, **Commit changes**. Then add its heading under `sections:` in [`_data/gallery.yml`](../../../_data/gallery.yml).
- **More photos for a conference already here:** open its folder and upload them there.

Please read the [photo guidelines](../README.md) first (JPG or PNG, resized, public-safe).
