# Defenses and graduations

Photos in this folder appear in the **Defenses and graduations** album on the [Gallery page](https://utacousticmems.github.io/gallery/).

**No dates in this album.** Name files without a date (for example `phd-defense-4.jpg`), keep dates out of captions, and remove the photos' hidden metadata (date taken, location) before uploading.

To add photos: **Add file → Upload files**, drag them in, **Commit changes**. Please read the [photo guidelines](../README.md) first (JPG or PNG, resized, public-safe).
